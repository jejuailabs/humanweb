# humanweb — YEON (연, 緣)

MBTI·사주·별자리·혈액형·손금 등 나를 해석하는 체계를 한곳에 모아 10개 스탯으로 종합하고, 매일의 운세와 한 줄 일기로 나를 기록하며, 비슷한 사람들과 이어지는 공간.

- 작업 규칙: [`CLAUDE.md`](CLAUDE.md)
- 기획 문서: [`docs/`](docs/00_OVERVIEW.md)

## 시작하기

```bash
npm install
cp .env.example .env.local   # 값 채우기
npm run dev                  # http://localhost:3000
```

## 스택
Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · next-intl (ko/en) · Firebase · Vercel
