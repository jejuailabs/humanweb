# 09. 네트워크·매칭

> 전체 기능과 함께 개발한다. 아래 "별도 결정 필요" 항목은 구현 전에 확정한다.

## 연결 점수 `[자체 설계]`
```
score = 0.40 × 스탯 유사도(코사인, 0~100)
      + 0.25 × 사주 궁합
      + 0.15 × 업종 일치
      + 0.10 × 지역 일치
      + 0.10 × 학교 일치
```
- 공개하지 않은 항목은 해당 가중치를 빼고 재정규화
- 사주 궁합 계산식 `[미정]` (일간 오행 상생·상극, 지지 합·충 등)

## 선 표시
| 점수 | 표시 |
|---|---|
| < 50 | 표시 안 함 |
| 50–69 | 흐린 선 (`--line-faint`) |
| 70–89 | 진한 선 (`--line-strong`) |
| ≥ 90 + 사주 합 관계 | **빨간 선** (`--fate-red`) |

- 빨간 선은 한 사람당 **최대 3개** (희소성)
- 시스템 추천 = 점선 / 서로 연결 수락 = 실선
- 지도에는 점수 상위 50명까지

## 계산 방식
1. Firestore 벡터 검색으로 스탯 유사 후보 추출 (10차원)
2. 후보와 최종 점수를 Cloud Function에서 계산 → `connections/{edgeId}` 저장
3. 프로필·공개 범위 변경 시에만 재계산

## 공개 일기 연동
- 스탯이 비슷한 사람의 공개 한 줄을 추천 피드로 보여줌

## 별도 결정 필요 `[미정]`
- 연결 요청·수락 흐름, 한쪽만 연결된 상태 표시
- 차단·신고·사칭 방지·학교/직장 인증
- 공개 범위 세분화 (전체 / 연결된 사람만 / 비공개)
- 이용 연령
