# 08. 어드민

## 접근
- Firebase Auth custom claim `admin: true` (부여는 서버 스크립트로만)
- `/[locale]/admin/**` 미들웨어 + 서버에서 클레임 확인
- 보안 규칙에서도 `request.auth.token.admin == true` 확인 (화면 숨김만으로 보호하지 않음)

## 대시보드 (한 화면)
| 영역 | 내용 | 우선순위 |
|---|---|---|
| 핵심 지표 | DAU, MAU, 신규 가입, D1/D7/D30 재방문율 | P0 |
| 오늘의 콘텐츠 상태 | 카테고리·언어별 `ok/retried/backup/failed`, 재생성 버튼, 미리보기 | P0 |
| 참여도 | 데일리 조회 수, **일기 작성 수(공개/비공개 비율)**, 스트릭 분포, 공유 카드 수 | P0 |
| 분석 퍼널 | 가입 → 생년월일 → 태어난 시간 → MBTI → 사주 → 손금 단계별 완료율 | P1 |
| AI 사용량 | 일별 호출 수·예상 비용(기능별: 데일리/보고서/대화/손금), 사용자별 상위 | P0 |
| 사용자 분포 | 언어, 지역, 연령대 | P1 |
| 신고 대기 | 공개 일기 신고 목록 | P1 |

## 개인정보 원칙
- 어드민도 **비공개 일기 원문과 AI 대화 원문은 기본적으로 열람하지 않는다.** 대시보드에는 집계 수치만.
- 신고된 **공개** 일기만 원문 확인 가능
- 열람·조치 기록은 `adminLogs`에 남긴다
- 법적 요청 대응 절차 `[나중에]` `[확인 필요]`
