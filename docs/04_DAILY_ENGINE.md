# 04. 데일리 운세 엔진

## 원칙
**계산은 코드, 문장은 AI, 검사는 코드, 사용자는 저장된 것만 읽는다.**

## 전체 흐름
```
[매일 00:00 KST] Cloud Scheduler → generateDaily 함수
  ① 재료 계산 (코드)
  ② AI 문장 생성 (언어별)
  ③ 출력 검사 (스키마, 금지어, 최근 7일 중복)
  ④ 실패 시 재시도 2회 → 그래도 실패하면 backupPool
  ⑤ daily/{date}/{lang}/{category} 저장, dailyMeta 상태 기록
[사용자 접속] 저장된 문서 읽기 (AI 호출 없음)
```
- 해외 사용자를 위해 **D+1(내일)까지 미리 생성**해 둔다. 사용자는 현지 날짜 키로 읽는다.

## ① 재료 계산
| 재료 | 방법 |
|---|---|
| 일진·음력·절기 | 만세력 라이브러리/자체 구현. 라이브러리 선정 `[확인 필요]` |
| 카테고리별 점수 | `seededRandom(hash(date + category + key))` → 0~100. 같은 날 같은 대상은 항상 동일 `[자체 설계]` |
| 띠 근거 | 오늘 일진 지지 ↔ 각 띠 지지의 합·충 관계로 점수 보정 |
| 별자리 근거 | 날짜·요일·달 위상 키워드 `[자체 설계]` |
| 혈액형·MBTI 근거 | 시드 점수 + 유형별 성향 키워드 `[자체 설계]` |
| 키워드 | 점수 구간별 키워드 풀에서 시드로 선택 |

> 별자리·혈액형·MBTI 데일리 운세는 공인된 계산 기준이 없다. 위 규칙은 일관성을 위한 자체 규칙이다.

## ② AI 생성
### 생성 단위
| 대상 | 개수/일/언어 |
|---|---|
| 별자리 | 12 |
| 혈액형 | 4 |
| 띠 | 12 |
| MBTI | 16 |
| 일간별 운세 (10천간 × 오늘 일진) | 10 |
| **합계** | **54** |

카테고리 단위로 묶어서 호출 (예: 별자리 12개를 한 번에 JSON 배열로). 언어 수만큼 반복.

### 프롬프트 템플릿
```
너는 따뜻하고 긍정적인 운세 작가야. 언어: {lang}
아래 재료로 각 대상의 오늘 운세를 써줘.

[재료]
날짜: {date} ({weekday}), 일진: {dailyPillar}
대상별: { key, scores, keywords }[]

[규칙]
- summary 1문장, detail 2~3문장, 조언형 말투
- 금지: 죽음, 사고, 질병, 흉하다, 불길하다 등 공포를 주는 단정
- 점수를 바꾸거나 언급하지 말 것 (점수는 화면에 따로 표시됨)
- 최근 7일 문장과 표현이 겹치지 않게: {recentSummaries}
- 용어는 용어집을 따를 것: {glossary}
- 지정 JSON 스키마로만 응답
```

### 출력 스키마
```json
{ "items": [ { "key": "aquarius", "summary": "string", "detail": "string",
  "lucky": { "color": "string", "number": 0, "direction": "string", "item": "string" } } ] }
```
점수는 AI 출력에서 받지 않고 ①의 값을 병합해 저장.

## ③ 검사
- JSON 스키마 일치, 모든 key 존재
- 금지어 사전 매칭 (언어별 사전)
- 길이 제한 (summary ≤ 60자, detail ≤ 200자, 한국어 기준. 다른 언어는 비율 조정)
- 최근 7일 summary와 유사도 임계값 초과 시 재생성 `[자체 설계]`

## 개인 운세
```
사용자 접속 → users/{uid}/daily/{date} 있음? → 표시
            └ 없음 → 내 일간 조회 → dayMasterDaily/{date}/{lang}/{stem} 가져오기
                    → (P1) 사주 다른 요소로 개인화 문장 추가 생성
                    → 저장 → 표시
```
- 태어난 시간 모름: 일간은 생년월일로 정해지므로 개인 운세는 가능 (시주만 빠짐)
- 토정비결: 연 1회 `tojeong/{uid}_{year}` 생성. 계산 방식(상·중·하괘, 144괘) 기준 문헌 `[확인 필요]`. 풀이 문장은 AI로 새로 작성 (시중 풀이집 문장 복제 금지)

## 데일리 스탯 보정 (P1)
- 오늘 일진과 내 일간의 십신 관계 → 스탯 2~3개 ±(3~10) `[자체 설계]`
- 표시 전용. `stats/current`는 바꾸지 않음

## 모니터링
- `dailyMeta/{date}`: 카테고리·언어별 `ok | retried | backup | failed`
- 하나라도 `backup`/`failed`면 어드민 대시보드에 경고
