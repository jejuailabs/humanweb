# 01. 기능 목록과 우선순위

우선순위: **P0** = MVP 필수 / **P1** = MVP 직후 / **P2** = 2단계 / `[나중에]` = 범위 밖

## A. 계정·온보딩
| 기능 | 우선순위 | 설명 |
|---|---|---|
| 소셜 로그인 | P0 | 구글·애플·카카오. 카카오는 Firebase 기본 제공이 아니라 커스텀 토큰 연동 필요 `[확인 필요]` |
| 최소 가입 | P0 | 닉네임, 생년월일(양력/음력), 혈액형 → 별자리·띠·혈액형 운세 즉시 오픈 |
| 추가 정보 요청 | P0 | 태어난 시간("모름" 허용), 성별 → 사주·개인 운세 오픈 |
| 생년월일 변경 제한 | P1 | 변경 횟수 제한 정책 `[미정]` |

## B. 데일리 콘텐츠 (재방문 핵심)
| 기능 | 우선순위 | 기준 | 갱신 |
|---|---|---|---|
| 오늘의 개인 운세 | P0 | 내 일간 × 오늘 일진 | 매일 |
| 오늘의 별자리 운세 | P0 | 12별자리 | 매일 |
| 오늘의 혈액형 운세 | P0 | 4종 | 매일 |
| 오늘의 띠 운세 | P0 | 12띠 | 매일 |
| 오늘의 MBTI 한마디 | P0 | 16유형 | 매일 |
| 행운 요소 | P0 | 색·숫자·방향·아이템 | 매일 |
| 토정비결 | P1 | 음력 생년월일 + 나이. 작괘: 상괘 (세는나이+태세수)%8, 중괘 (생월 날수+월건수)%6, 하괘 (생일+일진수)%3, 선천수 기준 `[자체 설계]`. 월별 점수는 코드, 문장은 AI | 연 1회, 월별 노출 |
| 데일리 스탯 보정 | P1 | 오늘 일진 → 스탯 ±10 표시 | 매일 |
| 지난 날짜 열람 | P0 | 데일리 대시보드 좌우 이동 | — |

## C. 한 줄 일기장
| 기능 | 우선순위 | 설명 |
|---|---|---|
| 하루 한 줄 작성 | P0 | 날짜당 1개, 최대 100자 (글자 수 `[자체 설계]`, 조정 가능) |
| 기분 태그 | P0 | 이모지 5종 중 선택 (선택 사항) |
| 공개/비공개 | P0 | 항목별 설정. **기본값 비공개**. 설정에서 기본값 변경 가능 |
| 운세와 함께 보기 | P0 | 그날의 운세 요약·점수와 일기를 한 화면에 나란히 기록 |
| 수정·삭제 | P0 | 언제든 가능. 공개 항목 삭제 시 공개 사본도 즉시 삭제 |
| 공개 일기 둘러보기 | P1 | 다른 사람의 공개 한 줄을 날짜별 피드로 열람 |
| 공감(하트) | P1 | 공개 일기에 하트만. 댓글은 `[나중에]` |
| 신고 | P1 | 공개 일기 신고 버튼 (공개 콘텐츠가 생기므로 최소한 필요) |
| "N년 전 오늘" | P2 | 과거 같은 날짜의 일기 다시 보기 |
| 월간 회고 | P2 | 한 달 일기 + 운세를 AI가 요약 (AI 사용 동의 시) |
| 비슷한 사람의 한 줄 | P2 | 스탯 유사 사용자의 공개 일기 추천 (네트워크 단계) |

## D. 분석 (프로필에 남는 것)
| 기능 | 우선순위 | 설명 |
|---|---|---|
| MBTI 검사/입력 | P0 | 자체 성향 검사 20~40문항 또는 유형 직접 입력. "MBTI" 명칭 사용 가능 여부 `[확인 필요]` (상표) |
| 사주 풀이 | P0 | 만세력 계산 + AI 해석 |
| 별자리·혈액형·띠 | P0 | 가입 정보로 자동 |
| 손금 분석 | P1 | 카메라 촬영 → AI 이미지 분석. 분석 후 원본 삭제가 기본값 |
| 이름 명리 | P2 | 한글 이름 발음오행(훈민정음 해례 기준)·자모 획수 4격을 코드로 계산, 해석만 AI. 이름 원문은 저장·AI 전송 안 함. 한자 획수는 사전 데이터 필요로 제외 `[자체 설계]` |
| 관상 | P2 | 손금과 같은 방식: 동의 체크 후 촬영 → AI 인상 분석, 사진 저장 안 함. 나이·성별·인종·건강·외모 판단 금지. 법률 검토(민감정보 해당 여부)는 여전히 `[확인 필요]` |
