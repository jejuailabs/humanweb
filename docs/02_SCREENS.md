# 02. 화면 구성과 흐름

## 내비게이션 (하단 탭 5개)
전체 기능을 함께 개발하므로 네트워크를 포함한 최종 구성으로 시작한다.

| 탭 | 화면 |
|---|---|
| 홈 | 종합 대시보드 |
| 오늘 | 상단 전환: **운세**(데일리 대시보드) / **일기**(한 줄 일기장) |
| 분석 (가운데 강조) | 분석 허브 |
| 지도 | 네트워크 지도 → `09_MATCHING.md` |
| 나 | 마이페이지·설정 (AI 대화 진입 포함) |

- **상단 벨 아이콘**(모든 탭 공통): 연결 요청·수락 알림
- **AI 대화** 진입: 홈의 "AI와 이야기하기" 버튼, 나 탭
- **공개 일기 둘러보기**: 오늘 탭 → 일기 → 둘러보기
- **사용자 간 메시지**: 기능 여부 `[미정]`. 정해지기 전에는 탭·버튼을 두지 않는다.
- 목업 이미지(`images/`)의 하단 탭(Map/Discover/Analyze/Messages/Profile)은 따르지 않는다. 목업은 색·질감·카드 스타일 참고용이다.

## 흐름
```
온보딩 → 홈(종합)
          ├─ 오늘의 요약 카드 ─▶ 데일리 대시보드 ─▶ "한 줄 남기기" ─▶ 일기 작성
          ├─ 스탯 차트 ─▶ 스탯 상세 (근거 분석별 기여도)
          ├─ 분석 카드 ─▶ 분석 상세 풀이
          ├─ AI 보고서 카드 ─▶ 보고서 전문 / 이전 버전
          ├─ "AI와 이야기하기" ─▶ AI 대화
          └─ (지도 탭) ─▶ 프로필 ─▶ 매칭 상세 ─▶ 연결 요청
```

## 1. 온보딩
1. 언어 선택 (기기 언어 자동 선택, 변경 가능)
2. 로그인
3. 닉네임 → 생년월일(양/음력 토글) → 혈액형
4. 완료 즉시 오늘의 별자리·띠·혈액형 운세 노출 ("벌써 오늘의 운세가 준비됐어요")
5. 태어난 시간·성별은 홈 카드로 나중에 요청

## 2. 홈 — 종합 대시보드 ("나는 어떤 사람인가")
- 상단: 프로필 사진, 닉네임, AI 한 줄 타이틀, 배지(MBTI·별자리·띠·혈액형)
- **오늘의 요약 카드**: 총운 점수 + 한 줄 요약 + 스트릭 + 오늘 일기 작성 여부. 탭 → 데일리
- 10축 레이더 차트: 미완료 분석과 연결된 축은 흐리게 + 잠금 아이콘. 신뢰도 % 표시
- AI 종합 보고서 요약 카드
- 분석 카드 가로 스크롤: MBTI / 사주(오행 막대) / 손금 …
- 프로필 완성도 (예: 4/7)
- "AI와 이야기하기" 버튼

## 3. 오늘 — 데일리 대시보드 ("오늘의 나는 어떤가")
- 상단: 날짜, 음력, 일진, ◀ ▶ 날짜 이동, 총운 점수 링
- 행운 요소 4종
- 데일리 스탯 보정 ("오늘 직관력 +8")
- 카테고리 탭: 내 운세 / 별자리 / 혈액형 / 띠 / MBTI (언어권별 탭 순서 설정 가능)
  - 각 탭: 한 줄 요약, 상세 2~3문장, 애정·금전·업무 점수
- 이번 달 토정비결 (접힘)
- **오늘의 한 줄 카드**: 작성 전이면 입력창, 작성 후면 내용 + 공개 상태 아이콘
- 공유 버튼
- 지난 날짜로 이동하면 그날의 운세 + 그날의 일기를 함께 표시 (기록장 역할)

## 4. 한 줄 일기장 (오늘 탭 → 일기)
- **보기 전환**: 달력 보기 / 목록 보기
  - 달력: 날짜마다 기분 이모지, 일기 있는 날 점 표시
  - 목록: 최신순, 각 항목에 그날 총운 점수·운세 요약 한 줄 함께
- **작성/수정 시트**
  - 입력창 (최대 100자, 남은 글자 수 표시)
  - 기분 이모지 5종 (선택)
  - 공개 토글: 🔒 나만 보기(기본) / 🌐 공개
  - 공개 선택 시 안내: "닉네임과 함께 다른 사람에게 보여요"
- **둘러보기 탭** (P1): 오늘 공개된 한 줄 피드, 하트, 신고
- 빈 상태: "오늘을 한 줄로 남겨보세요. 1년 뒤의 내가 읽게 될 거예요."

## 5. 분석 허브
- 진행 단계 표시 (예: 3/6)
- 카드 목록: 완료(골드) / 가능(보라 펄스) / 잠김(흐림+자물쇠)
- 손금: 카메라 화면 → 손 윤곽 가이드 → 분석 진행률 → 결과. "사진은 분석 후 삭제돼요" 안내

## 6. AI 대화
- 상단: "나를 아는 YEON" + 현재 반영 중인 정보 요약 칩 (스탯, MBTI, 사주, 오늘 운세, [일기: 허용 시])
- 대화 영역, 추천 질문 칩 ("요즘 나에게 맞는 일은?", "오늘 어떻게 보내면 좋을까?")
- 하루 남은 대화 횟수 표시
- 메뉴: AI 기억 보기·삭제, 일기 사용 허용 토글

## 7. 나 (마이페이지·설정)
- 프로필 편집, 기본 정보(생년월일 등)
- 공개 범위 설정 (항목별 공개/비공개)
- 일기 기본 공개 설정, 일기의 AI 사용 허용
- 언어, 테마(시스템/라이트/다크)
- 알림 `[나중에]`, 계정 탈퇴

## 8. 지도 — 네트워크 → `09_MATCHING.md`
- 상단 필터 칩: 전체 / 업종 / 지역 / 학교 / 나와 비슷한
- 가운데 나, 주변에 연결 후보와 인연선 (점수별 흐린 선·진한 선·빨간 선)
- 프로필 탭 → 매칭 상세 (두 사람 스탯 비교, 연결 이유, 연결 요청)
- 연결 요청·수락 흐름, 차단·신고 `[미정]`

## 9. 어드민 → `08_ADMIN.md`
