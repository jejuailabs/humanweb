### 단가 `[확인 필요]`
- 1:1 이외 비율(9:16, 3:4 등)의 단가
- 투명 배경(`background: transparent`) 옵션의 단가
- 레퍼런스 이미지를 넣었을 때의 단가

→ 해당 에셋을 처음 생성하기 전에 비용 조회로 확인한다. 비용 조회도 실행 전에 승인받는다.

## 원칙
1. **작은 아이콘은 AI로 만들지 않는다.** 배지, 탭 아이콘, 기분 이모지, 스탯 아이콘, 자물쇠 같은 것은 SVG(lucide 등)로 만들고 `currentColor`와 CSS 변수로 색을 넣는다. (절대 규칙 8)
2. **일러스트는 투명 배경으로 만든다.** 다크와 라이트 테마 위에 모두 올릴 수 있어야 한다. 배경이 필요한 것(배경 텍스처, 공유 카드)만 테마별로 따로 만든다.
3. **스타일 고정.** 승인된 샘플을 레퍼런스로 넣어 모든 시리즈의 그림체를 맞춘다.
4. **텍스트는 이미지에 넣지 않는다.** 모든 문구는 다국어 파일로 관리한다. (절대 규칙 7) 프롬프트에 항상 `No text, no letters` 를 넣는다.
5. **불안을 주는 이미지는 쓰지 않는다.** 해골, 피, 깨진 거울, 어두운 그림자 인물 등을 금지한다. (절대 규칙 6)
6. **`[나중에]` 항목의 에셋은 만들지 않는다.** 네트워크·매칭은 전체 개발에 포함되므로 만든다(7단계). 인연선과 지도 노드는 코드(SVG/WebGL)로 그리고, 이미지는 배경과 빈 상태만 만든다.

## 파일 규칙
- 경로: `public/assets/{분류}/{이름}.webp`
  - 분류: `bg`, `onboarding`, `zodiac`, `animal`, `blood`, `element`, `mbti`, `analysis`, `empty`, `avatar`, `share`, `lucky`, `video`
  - 이름: 영문 소문자 케밥. 예: `zodiac/pisces.webp`, `mbti/infj.webp`
- 원본 PNG는 저장소에 넣지 않는다. WebP로 변환해 저장한다.
- 생성 기록: `docs/assets/PROMPTS.md`에 에셋, job id, 프롬프트, 모델, 설정, 날짜, 채택 여부를 남긴다.
- 확인: 다크·라이트 두 모드에서 실제 화면에 얹어 본 뒤 채택한다.

## 진행 방식 (매 단계 공통)
1. 해당 단계의 에셋 목록, 프롬프트 초안, 예상 크레딧을 보여준다.
2. 승인을 받는다.
3. 생성하고, 결과를 보여준다.
4. 채택하거나 재생성한다. 재생성도 다시 승인받는다.
5. 실제 차감액을 잔액으로 확인하고 이 문서의 표를 갱신한다.
